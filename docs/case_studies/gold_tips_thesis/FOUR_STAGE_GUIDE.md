# 四阶段补齐：论文案例使用说明

## 1. 核验结果与边界

运行 `scripts/audit_thesis_data.py` 可复核项目内的两份数据，生成 `verified_data.json`。
2026-10-21核验：4540行输入生成4538行输出；日期完全一致，14个数值字段在绝对容差1e-12、相对容差1e-10内一致。
这证明现有转换文件与该配方一致，不证明上游数据没有偏差。原文件未覆盖。
CPI对齐方向问题、GPR/ETF发布日期问题仍未修复：缺少发布时间证据，不能自行猜测。当前只适合带风险说明的案例展示，不能称为已清除前视偏差的正式研究数据。

## 2. 绑定说明

字典使用文件SHA256绑定，不按文件名或相似列名猜测。上传论文水平数据、已核验转换数据或本工具生成的对应版本后，会显示字段定义、公式、来源和风险。
其他数据不会自动继承论文单位。报告只有匹配已核验版本且处理为t_diff、结果为y_ret时，才补充10基点冲击的近似百分比解释。

## 3. 数据准备

上传水平数据后，在“数据说明、处理与知识依据”阅读配方；确认短期目标及风险后生成独立CSV和处理记录。在“本次分析使用哪个版本？”选择“转换版本（短期变化）”，即可直接继续，无需下载重传。预览、字段选择和执行使用同一版本；切换时清除旧结果与审批配置，需要重新确认角色与研究方案。可切回“原始上传版本”，原始内容不变；下载按钮仍可用于留档。
转换不覆盖原文件，记录输入/输出校验值、行数、ADF检查及未解决风险。正值对数条件、日期顺序、重复、缺失或非数值不合格时拒绝转换。不是自动试遍转换直到检验通过。
本轮配方仅覆盖核验过的论文数据，不是任意数据自动清洗器；长期协整/误差修正模型仍不支持。

## 4. 解释、比较与知识辅助

结果页可下载本次方案JSON。重新按预先确定的方案运行后上传旧JSON，比较各期估计、区间、样本量与完整配置。数据版本、处理结果变量、效应类型或累计口径不一致时不直接比较。不自动推荐最显著方案。
绑定资料采用本地关键词检索加可追溯原文展示，无API费用，不会跨案例套用。这是有限的检索辅助，不是已完成通用语义RAG或自由生成研究建议。找不到资料明确返回无依据。
通用方法知识库、任意数据字典上传和发布日期驱动的数据重建属于后续扩展，当前没有冒充完成。
