# 控制方案选择

快速引导确认研究设计后，不再展示默认全字段列表，而是先选择控制方案。

- 基础案例方案：美元指数变化、标普500收益率、联邦基金利率变化、VIX水平，共4项。
- 扩展案例方案：上述4项，加COMEX库存变化、ETF持仓变化、CPI同比、5年盈亏平衡通胀率和GPR，共9项。含未解决日期风险，只作明确标注的探索比较。
- 自定义：自行选择字段，也可明确确认不使用控制变量。不是自动发现混杂。

预设仅对文件校验值匹配、转换已核验、处理为t_diff、结果为y_ret的时间序列案例开放。其他数据或反向问题仅显示自定义，不继承案例角色。

两组预设均不额外加入time_trend、y_ret_lag1、t_diff_lag1。扩展9项方案不同于以前全选12项的方案；历史比较应保留完整配置，不能混称同一方案。

每项展示业务类别、含义与限制。采用前必须确认；改选另一组方案需要重新确认。模型对控制字段使用的滞后阶数仍在高级设置中核对。预设不是已识别的因果控制集合，也不能消除上游样本选择问题。
