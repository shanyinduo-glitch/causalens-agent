# 简明分析流程

1. 上传数据并说明问题，确认影响因素和观察结果。
2. 描述研究背景，按提示完成预检；确认按钮始终显示，不满足条件时会禁用。未确认方案时不展示后续配置。
3. 确认方案后，补充必要的控制变量与研究背景，再开始分析。不要全选数值字段作为控制变量。
4. 执行完成后先阅读“发现了什么、影响大约多大、可以下什么结论、下一步做什么”。需要审计时再展开统计表、诊断和模型参数。

下载的时间序列报告也包含相同的简明结论，后面保留技术详情。摘要直接来自统计输出，不调用模型，不改变计算结果；缺少变量单位时不自动换算百分比。不是所有数据都能继续执行：转换方案、长期水平关系和因果外生性仍需要进一步研究。

本轮范围为引导页面与时间序列报告，其他研究设计的报告尚未统一成相同摘要格式。
